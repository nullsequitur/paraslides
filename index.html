Zero-Dependency Browser Engine

paraslides

Parallel decks for extra slides, parallax depth, and paragliding through 3D slides all at once.

Navigate horizontally with h / l or ← / →. Switch thematic sections vertically with j / k or ↓ / ↑.

Design Philosophy

Parallel Decks & Parallax Depth

Traditional slide decks force non-linear ideas into a rigid 1D strip. paraslides provides a sparse 3-axis coordinate space designed for high-density technical presentations.

HTML-First Portability

Runs natively in any modern browser directly from a file or static server with zero build steps or npm packages.

Strict Hexagonal Core

Pure JavaScript domain model completely decoupled from DOM elements, CSS styles, and event listeners.

Sparse Topology

Zero placeholder grid padding. Only genuine slides exist in both the DOM and internal coordinate tree.

Spatial Axis: Y

Vertical Axis: Thematic Sections

Sections represent major narrative themes or presentation chapters arranged along the vertical Y-axis (j / k).

Cursor Memory

Switching between sections remembers the last visited page on that row (lastX[y]) and restores it seamlessly.

Natural Hierarchy

Organize top-level topics vertically without disrupting horizontal slide progressions.

Spatial Axis: X & Z

Attached Detour Sequence

Pages progress horizontally (h / l). Any page can host an attached Z-axis detour sequence for technical deep-dives or backup slides.

Notice the glowing orange indicator at the bottom right. Press i now to enter this page's attached Detour Track!

Detour Track • Depth 1/2

Detour Track: Deep-Dive Details

You are now in DETOUR_MODE at coordinate (y=1, x=1, z=1).

Detour slides branch off from the main narrative track without disturbing the top-level flow. Horizontal navigation (h / l) now scrubs through the attached detour sequence.

Press l to view the next detour slide, or press o / Escape to return to the Main Track.

Detour Track • Depth 2/2

Detour Track: Visual Shift & Vertical Lock

The presentation canvas automatically shifts to the detour palette with subtle depth lighting.

Vertical Axis Lock

Vertical section switching (j / k) is strictly locked in detour mode to prevent disorienting jumps. Try pressing j to observe the HUD warning pulse!

Instant Return

Pressing o or Escape instantly returns you to the parent page (y=1, x=1, z=0) on the Main Track.

Spatial Mechanics

Vim & Arrow Coordinate Navigation

The navigation system models a deterministic finite state machine with strict boundary checking and cursor memory.

Main Track (z = 0)

h / l: Page sequence
j / k: Section switch
i: Enter detour (if available)

Detour Track (z > 0)

h / l: Scrub detour sequence
j / k: Locked (warning pulse)
o / Esc: Exit detour

Boundary Jumps

0: Jump to first slide on axis
$: Jump to final slide on axis

Interaction Contract

Keyboard Matrix & HUD Radar

All interactions map to Vim ergonomics and standard presentation clicker keys.

h / ← Move Left / Previous Slide (or scrub backwards in Detour)
l / → Move Right / Next Slide (or scrub forwards in Detour)
j / ↓ Move Down / Next Section (restores section page memory)
k / ↑ Move Up / Previous Section (restores section page memory)
i Enter Detour Mode (when supplementary slides exist)
o / Esc Exit Detour Mode (returns to parent slide)
0 / $ Jump to start / end of current axis
